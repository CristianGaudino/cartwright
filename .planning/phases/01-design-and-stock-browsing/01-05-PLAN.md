Test switch, stated on purpose: the demo provider is in memory and cannot fail, and a browser test cannot make a server render fail (aborting the RSC request makes Next fall back to a full page load). Only `playwright.config.ts` sets it, for the local server it starts. The #4 PR description names this as a trade-off for the owner.
