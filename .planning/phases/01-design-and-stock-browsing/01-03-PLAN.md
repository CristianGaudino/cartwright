The `fetch` command (network only, sequential, per D-04, D-10 and D-13). When it creates `.stock-cache/`, it first writes `.stock-cache/.gitignore` containing `*`. Network `get(url, init)` helper, used only by `fetch`: https only, host must be `www.cartwright.ie` or `c0.carsie.ie` (throw otherwise), header `User-Agent: cartwright-demo-build/1.0`, at least 1500 ms between requests to `www.cartwright.ie` and 300 ms between photo requests. Before sending, it appends one line to `.stock-cache/requests.log` in the interfaces format. No retry anywhere, in `get()` or its callers: any non-2xx or network error throws with the URL and status and the run exits 1; a later run sends only requests whose result is not yet cached, and the log keeps every request across runs so the reported total is the true total. At the end of every `fetch` run (success or failure), print the totals counted from the whole log: requests to `www.cartwright.ie` split into used-cars page, main.js, listing POST and car-details, and requests to `c0.carsie.ie`. `--limit N` applies the shared selection rule.
Step 1, the list (D-10, D-13): if `.stock-cache/list.raw.json` exists, read it and never send the POST again. Otherwise GET `https://www.cartwright.ie/used-cars/` once (skip when `used-cars.html` is cached) and save it; take the theme's `main.js` URL from a `<script src>` in that page and GET only that one file (skip when cached) and save it. If `main.js` does not contain `wp-json/api/v2/search/cars`, stop with exit 1 and report it: never fetch other scripts. Read from those two files: the nonce, the `X-WP-Nonce` header use, the content type, the request body the site sends for an unfiltered search, and any page-size or offset field. Send exactly that POST once, with the page-size field (if one exists) at or above the total the stock page shows. Write the response body to `list.raw.json` before parsing anything. Then validate: JSON; an array of listings found at a path you name in a constant; each listing has a digits-only id and a detail URL or slug. If validation fails, print the top-level keys, the first item's keys, the count and the expected total, and exit 1 (fail loudly; fix the mapping offline against the cached file, never by re-sending). Print `listTotal` and the page's total. Keep the nonce in memory only.
Step 2, details (D-13): for each selected listing, if the list item already carries make, model, year, price, fuel, transmission, body, odometer and photo URLs, skip the detail page; otherwise GET `/car-details/?{id}={slug}` once and save it to `cars/{id}/detail.html` (skip when cached). These are the only per-car requests to `www.cartwright.ie`.
Step 3, photos: candidate URLs on `c0.carsie.ie`, in page order, de-duplicated, preferring the URLs the markup marks as full-size gallery images. For each candidate until 6 are kept: GET it, read `sharp(buf).metadata()`, keep it only if width is 900 or more, save as `photo-{n}.jpg` and append `{ n, url, width, height }` to `photos.json`. Skip a car whose 6 photos (or its exhausted candidates) are already cached.

The `build` command (offline, deterministic, per D-02; it reads only `.stock-cache/` and never calls `get()`). Flags `--limit N` (the shared selection rule) and `--report`. For each cached car, read specs from the list item when present, else from the detail page's `<dt class="detail-list__title …">Label</dt><dd class="detail-list__text …">Value</dd>` pairs (Make, Model, Year, Price, Fuel Type, Body, Transmission, Odometer) and the `<h1 class="breadcrumbs__title">` title. Clean every scraped string: strip tags, decode HTML entities (named and numeric), collapse whitespace, trim, and replace U+2013 and U+2014 characters with a plain hyphen (CLAUDE.md bans them on the site). Normalise: `priceEur` from the digits of the price (skip the car if absent, with reason); `year` as an integer from 1950 to next year; `mileageKm` from the Kms figure only (undefined when there is none, never 0, Open Question 4); `fuel` by case-insensitive rules in this order: contains "plug" is plug-in-hybrid, contains "hybrid" or names electric with petrol or diesel is hybrid, "electric" is electric, "diesel" is diesel, "petrol" is petrol, anything else is other and its raw value goes in the report; `gearbox` is automatic when the text matches auto, dsg, cvt, tiptronic or semi, manual when it matches manual, else undefined; `bodyType` is the cleaned label and `bodySlug` its slug. `slugify` lowercases, strips diacritics (NFKD), turns runs of non-alphanumerics into one hyphen and trims hyphens. `slug` is `${makeSlug}-${modelSlug}-${year}-${id}` (D-08). Photos: encode each cached original in n order with `sharp(buf).resize(900, 675, { fit: "cover" }).webp({ quality: 72 })` (sharp drops EXIF and GPS by default; keep that default and do not opt into keeping metadata), name it `{n}-{sha1 of the output, first 8 hex}.webp` under `public/stock/{id}/`, and record `{ src: "/stock/{id}/{file}", width: 900, height: 675 }`. Skip a car with fewer than 3 usable photos (STK-02 "several"), with reason. Delete `public/stock/` before writing so no stale file survives (Pitfall 5). Write `src/lib/stock/demo-cars.json` per the output layout. `--report` prints one JSON object: `listTotal`, `carsBuilt`, `skipped` ([{ id, reason }]), `photos`, `bytes`, `avgPhotoKB`, `projectedMB` (average photo bytes x 6 x listTotal / 1e6), `unmappedFuel`.
