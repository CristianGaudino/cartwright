## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser URL -> server page | `page` and `q` are untrusted and choose the redirect target and the switch match |
| server env -> provider | An env var can change what `stock.query` does |
| provider failure -> HTML and logs | A thrown error must not leak into the page or the logs |

| T-01-26 | Denial of service | E2E failure switch in `src/lib/stock/index.ts` | low | mitigate | Active only when the server env var is set, which only the local Playwright server does; acceptance greps that its name is absent from `wrangler.jsonc`, `next.config.ts` and every workflow; the CI worker job requests `/used-cars?q=e2e-forced-failure` on the Worker build and fails unless it answers 200 without "We could not load the cars"; the #4 PR states the var must be absent from the Cloudflare vars and secrets; even if set, it fails only the request whose search equals it, shows the normal error state and logs nothing |
