## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> submitLead (multipart) | Untrusted files and sizes |
| Worker -> R2 (binding) | Private bucket, EU jurisdiction |
| email link -> /lead-photos | Anyone holding a link can request it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-30 | Tampering | uploaded files | high | mitigate | Magic-byte sniff, content type from the sniff, per-file, total and count caps, `nosniff` on serve, never decoded on the Worker |
| T-03-31 | Denial of service | large multipart bodies | medium | mitigate | 18 MB action body cap, 16 MB server total, 12 files; 03-01 A5 proved the Worker handles it; 03-14 adds the client re-encode and total check |
| T-03-32 | Information disclosure | photo links | high | mitigate | Random UUID prefixes, HMAC-SHA256 with a Worker secret, 7-day expiry, `trade-in/` prefix check, constant-time verify, `private, no-store`, `noindex`; 403 before any bucket read |
| T-03-34 | Information disclosure | bucket exposure | high | mitigate | No public access, no custom domain; read only through the signed route |
| T-03-35 | Information disclosure | orphan photos and retention | low | mitigate | Delete this request's keys when a put or the insert throws and when the insert returns false (concurrent double submit; int test); 365-day lifecycle rule (or the A6 fallback in 03-14's runbook) |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installed in this plan (R2 binding and Web Crypto replace aws4fetch) |
</threat_model>
